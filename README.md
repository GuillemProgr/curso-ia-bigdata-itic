# Curso de IA y Big Data (ITIC BCN)

Repositorio con las prácticas y ejercicios que voy haciendo durante la Especialización en Inteligencia Artificial y Big Data. Está en constante actualización: iré añadiendo nuevas actividades a medida que avance el curso.

## Contenido

- **PRACTICA APPLES**: análisis de datos de manzanas.
- **PRACTICA IRIS**: introducción al machine learning con el dataset Iris.
- **PRACTICA VINS**: análisis del dataset de vinos.

## Tecnologías

Python y Jupyter Notebook.
